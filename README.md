# Mahābhārata Explorer

An interconnected, responsive Mahābhārata knowledge explorer.

> [!NOTE]
> The project is currently in **STAGE 0 — Antigravity Project Setup**. Implementation has **NOT** started yet.

## Overview

The Mahābhārata Explorer repository contains project documentation, future backend/frontend application areas, data management directories, test suites, and agent configurations.

The architecture and implementation will be developed in subsequent stages strictly according to the project's approved documentation.

## Repository Structure

- `docs/` - Project blueprint, detailed reference, PRD, and technical documentation.
- `.agents/` - Agent rules, workflows, and configuration.
- `apps/` - Web frontend and API application packages.
- `packages/` - Shared libraries and configuration packages.
- `data/` - Seed data, schemas, and research materials.
- `tests/` - Integration test suites and test fixtures.
- `scripts/` - Utility scripts and project automation.
